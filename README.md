# Swadesh Arena

Swadesh Arena is a sports booking and community platform developed using PHP, MySQL, HTML, CSS, and JavaScript.

The platform allows users to explore sports facilities and submit booking requests through a live web interface. An authenticated admin dashboard is used to view and manage submitted booking information.

## Live Demo

🌐 https://swadesh-arena.freepage.cc

## Features

- Responsive sports arena website
- Online booking request system
- MySQL database integration
- Booking information storage
- Protected admin login
- Admin booking dashboard
- Booking search and status filtering
- Secure admin logout
- Mobile-friendly interface

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- InfinityFree Hosting

## Admin Security

The administration dashboard is protected using password authentication and PHP sessions.

Sensitive credentials and administrator passwords are not included in this repository.

## Project Purpose

This project was developed as a practical web application demonstrating frontend development, backend development, database integration, authentication, and deployment.
